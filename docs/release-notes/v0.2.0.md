APU Astro 0.2.0：後製工作室拖滑桿時畫面即時更新、步驟清單重新整理（標準／阿噗流程）。出圖結果跟 0.1.7 完全一樣。

內含組件：APU Pick 0.9.0・APU Photons 0.4.1・APU Processing 0.2.4

## 下載

| 系統 | 檔案 |
|---|---|
| Windows 10 / 11（64 位元） | `APUAstro-0.2.0-win64.zip` |
| macOS（Apple 晶片 M1 以後） | `APUAstro-0.2.0-macos-arm64.zip` |
| macOS（Intel） | `APUAstro-0.2.0-macos-x86_64.zip` |

**Windows**：在 zip 上按右鍵 →「全部解壓縮」，雙擊 `APUAstro.exe`。出現「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」（程式沒有購買數位簽章）。

**macOS**：解壓縮後把 `APUAstro.app` 拖到「應用程式」。程式沒有 Apple 的開發者簽章，第一次打開會被擋：
到「系統設定 → 隱私權與安全性」，往下找到 APU Astro 按「強制打開」（較舊的 macOS 是在 App 上按右鍵 →「打開」）。
Mac 沒有 NVIDIA 顯示卡，疊圖和 AI 降噪都用 CPU，會比 Windows 開 GPU 慢。

## 後製：拖滑桿時即時看到

- **拖曳中畫面就會更新**（以前要放手才開始算）：先用更小的「互動預覽」每 0.1 秒左右更新一次，放手後換成快速預覽，停手後再算完整解析度，一層一層變清楚。拉伸、調色、校色、合成星點這類調整，拖曳到畫面更新大多在 0.1 秒內
- **放大看細節時自動只算看得到的那一塊**：放大到 50% 以上，畫面範圍自動當成預覽區，用完整解析度算那一塊（以前要自己框預覽區）
- **重算時畫面不清空**：保留上一張，右下角小小的顯示進度
- **預覽跟出圖更一致**：完整解析度算過一次之後，預覽改用完整解析度量到的統計（拉伸深淺、天空、白平衡），去星也沿用完整解析度的結果。LBN576 測試：預覽跟出圖的背景差距從 3.4 階降到 1.4 階、星點從 7.9 階降到 2.0 階。改用的那一次畫面會跳一下，左下角會註明
- **出圖結果跟 0.1.7 完全一樣**（逐位元相同）

## 後製：步驟清單重新整理

- **預設集**：清單上方選
  - **標準**（新的預設）：摺疊成 4 個階段（線性處理、去星與拉伸、調色與細節、合成），每個階段只露出關鍵滑桿；按箭頭或「展開細步驟」看全部參數。步驟跟阿噗流程一樣，成品相同
  - **阿噗流程**：列出全部 13 步
  - **自訂**：把目前的步驟與參數存成自己的預設集，之後開新圖直接套用
- **去星之後的步驟依分支分組**：無星圖分支、星點分支各一組，左邊一條顏色的線；合成星點標成匯合點。上下移只在同一組裡移動
- **影像左上角的狀態標籤**：隨時看得到現在顯示的是什麼，例如「第 2 步 去光梯度 · 背景模型 · 快速預覽」
- **「預覽與效能」**（停手後算完整解析度、使用 GPU）移到上方的齒輪按鈕，不再出現在每一步的面板底下
- 專案檔（.apuastro）會記住預設集與清單的顯示方式；0.1.x 存的專案照樣打得開（用完整清單顯示）
